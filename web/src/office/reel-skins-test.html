Reel skins

Three mounts of the same mountReel() from reel.js, same mock data (SAMPLE_EVENTS + seedEvents()), one store per panel so each can carry its own open/filter state. Left panel has a detail card open (paper, the default look). Middle panel is a normal list (glass). Right panel is filtered down to nothing, to check the empty state (ticker). Every panel's own cycle button in its head still works — click it to see any skin against any of the three states.

paper — default, detail card open

The original warm-card look. No skin CSS of its own — it's everything above the "reel skins" section, unscoped.

glass — dark translucent, normal list

Sits over the 3D scene in office.html; this gradient stands in for that so the blur has texture. Rung badges are the only saturated color, everything else is white at varying opacity.

ticker — dense monospace log, empty filter

No card chrome, single-line rows, terminal feel. Filtered to a human that matches nothing, to check the empty state reads fine against a flat dark panel.
